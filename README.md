# Freezer Tracker

A phone-first freezer inventory app for two people, planned to run on Databricks Free Edition with Unity Catalog managed Delta tables.

See [PLAN.md](PLAN.md) for the product scope, architecture, ACID transaction design, Free Edition constraints, milestones, and acceptance criteria.

## Status

Planning. No Databricks credentials or household inventory data belong in this repository. Keep credentials in environment variables or Databricks-managed secrets; never commit them.
